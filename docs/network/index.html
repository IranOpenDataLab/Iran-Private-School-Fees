🕸️ گراف شبکه مدارس (۲۴٬۶۴۸ مدرسه)

مختصات آفلاین و قطعی محاسبه شده؛ یال‌ها در مرورگر بازسازی می‌شوند. زنجیره موسس: خط سبز ضخیم = نام یکسان، خط‌چین کم‌رنگ = نام متفاوت. مقادیر ۱۴۰۵، وگرنه ۱۴۰۴.

برای شروع، دکمه بارگذاری را بزنید — فایل گراف (∼۳ مگابایت) دانلود و رندر می‌شود.

      📌 پنل ناحیه

      اندازه گره مدرسه = ‎3 + 25·√(آخرین شهریه ثبت‌شده / بیشینه) — رنگ = مقطع. برای دیدن فقط یک استان، منوی «تفکیک استانی» را باز کنید. در زوم پایین labelها مخفی‌اند؛ با اسکرول/درگ بزرگ‌نمایی کنید. داده گراف بعد از اولین دانلود در حافظه مرورگر می‌ماند.
